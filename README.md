# Python Chromium Browser

A minimal desktop web browser built with Python, `PyQt6`, and `QtWebEngine`.

## Features

- Address bar
- Back, forward, reload
- Simple browser chrome
- Chromium-based rendering via Qt WebEngine

## Run

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python browser.py
```
